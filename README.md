# Bravos Galateo Website (Prototype)

A prototype team website for **Los Bravos de Galateo Centro Master Senior Baseball League**.

## 🌐 Live Site
[View Website](https://exempr.github.io/Bravos-Galateo/)

## 📌 Project Status
🚧 Work in Progress (Prototype)

## 📖 Description
This project is a prototype baseball team website created to demonstrate the structure, layout, and design of a future full-featured site.

It showcases how team information can be organized in a clean, accessible, and visually appealing way.

## 🚀 Features
- Home section with team identity
- Roster section (basic structure)
- Upcoming game display
- Team statistics section
- Gallery section
- Sponsors section
- Contact information

## 🛠️ Technologies Used
- HTML
- CSS
- JavaScript

## 🎯 Purpose
The goal of this project is to demonstrate front-end development skills, including layout design, content organization, and deployment using GitHub Pages.
