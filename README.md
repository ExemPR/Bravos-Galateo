# Bravos Galateo Website

A team website for **Los Bravos de Galateo Centro Master Senior Baseball League**.

## Live Site
[View Website](https://exempr.github.io/Bravos-Galateo/)

## Description
This project is a baseball team website created to present team information in a clean and accessible way.  
It includes sections for the roster, upcoming games, statistics, gallery, sponsors, and contact details.

## Features
- Home section with team identity
- Basic roster section
- Upcoming game information
- Team statistics
- Gallery section
- Sponsors section
- Contact information

## Technologies Used
- HTML
- CSS
- JavaScript
